# Admin Guide

The admin shell is available at `/admin`.

Initial capabilities planned:

- Manage courses, services, resources, testimonials, FAQs, enquiries, media, navigation, homepage copy, footer copy, SEO metadata, social links, contact details, and WhatsApp settings.
- Publish, unpublish, feature, and reorder content.
- Export enquiries as CSV.
- View meaningful enquiry and content metrics.

The current starter includes the dashboard shell and protected analytics API. CRUD screens should connect to `/api/v1/admin/*`.
